# K线击败与反转信号发现记录

基于全市场 5062 只 A 股（2014-2026）的逐日 K 线数据，验证威科夫"努力 vs 结果"理论在 A 股的有效性，并分析高位放量 K 线的 A 杀规律。

---

## 理论背景

### 威科夫 Effort vs Result

成交量 = 努力（资金投入了多少），K 线实体/振幅 = 结果（价格移动了多少）。

- **努力大、结果小**：趋势衰竭（多头/空头弹尽粮绝）
- **努力小、结果大**：趋势有效突破（少量资金就能推动价格）

### K 线击败定义

**看涨击败**：一根放量阴线/十字星（关键 K 线）出现在低位，随后被一根阳线收破其高点。如果击败 K 线的成交量远小于关键 K 线，说明空头已经无力抵抗。

**看跌击败**：一根放量阳线/十字星（关键 K 线）出现在高位，随后被一根阴线收破其低点。如果击败 K 线的成交量远小于关键 K 线，说明多头已经弹尽粮绝。

### 检测代码

```python
def detect_defeat_signals(df, vol_ma20):
    """
    检测K线击败信号。

    关键K线（被击败者）：量比>1.5的阳线/阴线/十字星
    击败K线：收盘价突破关键K线的高点/低点，方向相反

    返回看涨击败和看跌击败两个列表。
    """
    close = df['close'].values
    open_ = df['open'].values
    high = df['high'].values
    low = df['low'].values
    volume = df['volume'].values
    n = len(close)

    bearish_signals = []  # 看跌击败
    bullish_signals = []  # 看涨击败

    for i in range(60, n - 10):
        if np.isnan(vol_ma20[i]):
            continue

        # 往前1-5天寻找关键K线
        for lookback in range(1, 6):
            ki = i - lookback
            if ki < 60:
                continue

            # 关键K线必须放量
            vol_ratio_k = volume[ki] / (vol_ma20[ki] + 1e-10)
            if vol_ratio_k < 1.5:
                continue

            bar_range_k = high[ki] - low[ki]
            if bar_range_k <= 0:
                continue

            body_k = close[ki] - open_[ki]
            body_pct_k = abs(body_k) / bar_range_k
            is_bullish_k = body_k > 0

            # 当前K线（击败者）
            bar_range_i = high[i] - low[i]
            if bar_range_i <= 0:
                continue
            body_i = close[i] - open_[i]
            body_pct_i = abs(body_i) / bar_range_i
            is_bullish_i = body_i > 0
            vol_ratio_i = volume[i] / (vol_ma20[i] + 1e-10)

            # 努力比 = 击败K线量 / 关键K线量
            effort_ratio = vol_ratio_i / vol_ratio_k

            # 前期趋势
            pre_trend = (close[ki] / close[ki - 5] - 1) * 100 if ki >= 5 else 0

            # === 看跌击败 ===
            if (is_bullish_k or body_pct_k < 0.3):  # 关键K线是阳线或十字星
                if close[i] < low[ki] and not is_bullish_i:  # 阴线收破低点
                    bearish_signals.append({
                        'effort_ratio': effort_ratio,
                        'pre_trend': pre_trend,
                        'body_pct_curr': body_pct_i,
                        'gap_days': lookback,
                    })

            # === 看涨击败 ===
            if (not is_bullish_k or body_pct_k < 0.3):  # 关键K线是阴线或十字星
                if close[i] > high[ki] and is_bullish_i:  # 阳线收破高点
                    bullish_signals.append({
                        'effort_ratio': effort_ratio,
                        'pre_trend': pre_trend,
                        'body_pct_curr': body_pct_i,
                        'gap_days': lookback,
                    })

    return bearish_signals, bullish_signals
```

## 1. 看涨击败：大跌后缩量击败 = 强反转（2025-06-26）

### 背景

看涨击败信号共 537,451 个。分析前期跌幅、努力比（击败量/关键量）与后续走势的关系。

### 基础率

| 时间 | 上涨率 | 不破关键低点 |
|------|--------|-----------|
| 3天 | 46.3% | — |
| 5天 | 46.5% | — |
| 10天 | 48.0% | 64.5% |

看涨击败的基础上涨率不到 50%，单独使用无预测力。

### 努力比（击败量/关键量）vs 后续

| 努力比 | 含义 | 5天上涨率 | 10天不破低 | 5天收益中位 |
|--------|------|----------|----------|-----------|
| <0.3 | 极小量击败 | **56.6%** | **85.2%** | **+0.97%** |
| 0.3-0.5 | 小量击败 | **52.7%** | 71.4% | +0.41% |
| 0.5-0.8 | 中量击败 | 48.6% | 64.3% | -0.12% |
| 0.8-1.2 | 平量击败 | 45.9% | 61.3% | -0.54% |
| >1.2 | 大量击败 | 42.3% | 68.3% | -1.12% |

**量越小的击败越可靠**。努力比 <0.3 时 5 天上涨率 56.6%，>1.2 时降到 42.3%。

### 前期趋势 vs 后续

| 前期5天跌幅 | 5天上涨率 | 10天不破低 | 5天收益中位 |
|------------|----------|----------|-----------|
| **大跌<-15%** | **75.3%** | **90.6%** | **+4.95%** |
| 跌-15~-5% | 51.2% | 74.0% | +0.21% |
| 小跌-5~0% | 48.1% | 70.0% | -0.14% |
| 微跌0~5% | 45.4% | 64.7% | -0.50% |
| 涨>5% | 42.2% | 59.4% | -1.35% |

**前期跌幅是最强信号**。大跌 >15% 后的看涨击败，75.3% 上涨，90.6% 不破关键低点，收益中位 +4.95%。

### 核心组合：大跌 + 缩量击败

| 前期10天跌幅 | 努力比 | 5天上涨率 | 10天上涨率 | 20天上涨率 | 10天不破低 | 20天收益中位 |
|-------------|--------|----------|----------|----------|----------|-----------|
| **大跌<-20%** | **<0.3** | **79.9%** | **75.5%** | **82.1%** | **91.2%** | **+12.2%** |
| **大跌<-20%** | **0.3-0.6** | **77.9%** | **75.3%** | **83.1%** | **89.2%** | **+15.1%** |
| 大跌<-20% | 0.6-1.2 | 74.0% | 73.4% | 80.7% | 85.2% | +15.8% |
| 大跌<-20% | >1.2 | 59.5% | 62.6% | 68.8% | 80.5% | +9.1% |
| 中跌-20~-10% | <0.6 | 57.4% | 58.6% | 62.7% | 80.3% | +3.8% |
| 小跌-10~-5% | <0.6 | 52.8% | 53.4% | 55.1% | 76.1% | +1.3% |
| 涨 | <0.6 | 46.6% | 48.4% | 48.2% | 65.2% | -0.6% |

### 大跌后缩量击败的详细分位数

条件：前期10天跌 >20% + 努力比 <0.6。样本：9,540 个信号。

| 时间 | 收益P25 | 收益P50 | 收益P75 | 收益P90 | 不破低率 |
|------|---------|---------|---------|---------|---------|
| 5天 | +0.7% | **+4.7%** | +12.5% | +19.8% | — |
| 10天 | +0.2% | **+5.7%** | +11.4% | +19.3% | **89.4%** |
| 20天 | +5.4% | **+14.8%** | +22.6% | +31.4% | **96.7%** |
| 10天最大涨幅 | +9.6% | +15.3% | +21.8% | +30.3% | — |
| 20天最大涨幅 | +12.7% | +20.0% | +28.8% | +41.3% | — |

### 击败间距的影响

| 击败间距 | 10天上涨率 | 10天不破低 | 收益中位 |
|---------|----------|----------|---------|
| **1天后** | **84.4%** | 86.0% | **+18.9%** |
| 2天后 | 71.2% | 83.5% | +7.8% |
| 3天后 | 75.5% | 88.9% | +6.5% |
| 4天后 | 76.2% | 89.7% | +5.9% |
| 5天后 | 74.9% | 91.4% | +4.3% |

越快击败越猛。1天后击败 84.4% 上涨率，收益中位 +18.9%，但样本少（307个）。3-5天后击败更稳定。

### 结论

1. 大跌后 + 缩量看涨击败 = **75-83% 上涨率**，20天收益中位 +15%。这是威科夫 Effort vs Result 在 A 股的量化验证。

2. "努力比"是核心指标。关键 K 线放巨量（空头全力出击），被小量阳线收破高点（多头轻松碾压）= 空头彻底投降。量比越小，信号越可靠。

3. 看涨击败远强于看跌击败。大跌后看涨击败 75-83% 上涨率，看跌击败仅 49% 下跌率。"底部反转"比"顶部反转"更容易量化。

4. 击败越快越猛。1天后击败收益中位 +18.9%，但信号稀缺。3-5天后更常见，收益递减但稳定性更好。

## 2. 看跌击败：几乎没有预测力（2025-06-26）

### 基础率

| 时间 | 下跌率 | 不破关键高点 |
|------|--------|-----------|
| 3天 | 49.2% | — |
| 5天 | 49.4% | — |
| 10天 | 50.7% | 66.6% |

看跌击败的基础 5 天下跌率仅 49.4%，接近随机。

### 努力比 vs 后续

| 努力比 | 5天下跌率 | 10天不破高 |
|--------|----------|----------|
| <0.3 | 51.2% | **80.2%** |
| 0.3-0.5 | 50.1% | 70.1% |
| 0.5-0.8 | 48.6% | 61.7% |
| >1.2 | 53.1% | 84.6% |

看跌击败的"10天不破关键高点"有 80% 概率，说明看跌击败预测的是**横盘**，不是下跌。

### 组合扫描

看跌击败的最佳组合 5 天下跌率仅 54.4%（极小量 + 前期跌 + 大实体），无组合超过 55%。

### 结论

看跌击败在 A 股几乎没有预测力。它更多预测"涨不动了"（横盘），而不是"要跌了"。

## 3. 高位放量 K 线与 A 杀（2025-06-26）

### 背景

A 股的"A 杀"（高位急跌）非常普遍。验证"一根高位放量 K 线就是反转信号"的直觉。

扫描条件：全市场所有量比 >2 倍的 K 线（658,123 根），分析其位置、形态与后续 A 杀概率。

A 杀定义：10 天内最大跌幅 >20%。

### 基础率

| 指标 | 数值 |
|------|------|
| 放量 K 线总数 | 658,123 |
| 5天下跌率 | 56.0% |
| 10天下跌率 | 55.0% |
| 10天A杀率 | 5.7% |
| 20天A杀率 | 12.2% |
| 10天最大跌幅中位 | -6.2% |

### 单因素分析

#### 位置 vs A杀

| 60日位置 | 10天A杀率 | 20天A杀率 | 10天最大跌 |
|---------|----------|----------|----------|
| 低位 0-50% | 4.4% | 9.7% | -5.4% |
| 中位 50-80% | 4.9% | 11.0% | -6.2% |
| 高位 80-90% | 6.4% | 13.2% | -6.8% |
| **极高位 90-100%** | **8.7%** | **16.5%** | **-7.3%** |

极高位 A 杀率是低位的 2 倍。

#### 量比 vs A杀

| 量比 | 10天A杀率 | 20天A杀率 | 10天最大跌 |
|------|----------|----------|----------|
| 放量 2-3 | 4.8% | 11.0% | -5.8% |
| 大量 3-5 | 7.0% | 14.0% | -7.2% |
| **巨量 5-10** | **12.1%** | **20.4%** | **-9.4%** |
| **爆量 >10** | **27.9%** | 0.2% | **-13.8%** |

**量比是最强的 A 杀预测因子**。爆量 >10 倍时近三成 A 杀。

#### 当日涨幅 vs A杀

| 当日涨幅 | 10天A杀率 | 20天A杀率 | 10天最大跌 |
|---------|----------|----------|----------|
| 当日小涨 0-3% | 3.4% | 8.6% | -5.1% |
| 当日涨 3-7% | 4.3% | 10.3% | -6.0% |
| **当日大涨 >7%** | **10.0%** | **18.7%** | **-8.2%** |
| 当日跌 -3~0% | 4.5% | 10.5% | -5.7% |
| 当日大跌 <-3% | 7.0% | 13.9% | -6.9% |

当日大涨 >7% 的 A 杀率是小涨的 3 倍。

#### K线形态 vs A杀

| 形态 | 10天A杀率 | 20天A杀率 |

| 阳线 | 5.3% | 11.9% |

| 无上影 <0.1 | **7.3%** | -6.8% |
| 小上影 0.1-0.3 | 4.7% | -5.9% |
| 中上影 0.3-0.5 | 5.2% | -6.2% |
| 长上影 >0.5 | 5.0% | -6.0% |

**无上影线的 A 杀率最高**（7.3%），而非长上影线。说明"光头阳线放量"比"长上影线放量"更危险——多头把价格打到最高点收盘，看似最强，实则透支了全部买力。

| 大量3-5 + 极高位 + 阳线 + 当日大涨 | 10.5% | **13.5%** | -8.4% | -2.8% | 25,688 |
| 放量2-3 + 极高位 + 阳线 + 当日大涨 | 9.4% | **13.1%** | -8.0% | -1.6% | 41,103 |

### A 杀画像

**最危险的单根 K 线**（10 天 A 杀率 26.7%）：

```
位置：60日最高位（>90%）
当日涨幅：>5%（大涨）
量比：>5倍（巨量）
形态：阴线（冲高回落）
```

这根 K 线就是典型的"A 杀起点"——多头在高位全力出击（巨量+大涨），但收盘被打回（阴线），此后大概率急跌。

**拉高出货型**（20 天 A 杀率 24.5%）：

```
位置：60日最高位（>90%）
当日涨幅：>5%（大涨）
量比：>5倍（巨量）
形态：阳线（收在最高点）
```

阳线的 A 杀来得更晚——10 天仅 15.4%，但 20 天跳到 24.5%。说明"拉高出货"需要更多天才完成：先涨几天吸引散户跟风，再集中出货杀跌。

### 结论

1. **"一根高位放量 K 线就是反转信号"在 A 股被数据验证。** 极高位 + 大涨 + 巨量的组合，10 天 A 杀率 15-27%，10 天最大跌 -8% 到 -15%。

2. **量比是最强的 A 杀预测因子**（5.8 倍差距）。爆量 >10 倍近三成 A 杀，放量 2-3 倍仅 4.8%。

3. **阴线比阳线更危险**。极高位+大涨+巨量，阴线 26.7% vs 阳线 15.4%。阴线说明当天就被打下来了，多头已失守。

4. **阳线的 A 杀来得更晚**。阳线组合 20 天 A 杀率（24.5%）远高于 10 天（15.4%），典型的"拉高出货"节奏。

5. **无上影线比长上影线更危险**。"光头阳线放量"看似最强，实则透支了全部买力，A 杀率 7.3% 高于长上影线的 5.0%。

6. **信号不稀缺**。极高位+大涨+放量的组合有几万个样本，说明 A 股确实"A 杀特别多"。

7. **巨量阴线下跌后，超一半概率 40 天内不创新高**。巨量>5 + 阴线 + 当日跌的组合，20 天不创新高 60.8%，40 天不创新高 50.6%。这根 K 线不只是"A 杀起点"，更可能是**中长期顶部**。

## 方法备注

- 数据来源：A 股全市场 5062 只个股日线数据（2014-01-01 至 2026-06-25）。
- K 线击败分析基于全市场 1,433,331 个击败信号（看跌 894,132 + 看涨 539,199）。
- A 杀分析基于全市场 658,123 根量比 >2 倍的 K 线。
- 努力比 = 击败 K 线成交量 / 被击败关键 K 线成交量。越小说明击败越轻松（对手已无力抵抗）。
- 位置 = 当日收盘价在近 N 日最高价-最低价区间中的百分位。0% = 最低，100% = 最高。
- A 杀定义：分型后 N 天内最大跌幅 >20%。
- 上影线比例 = (最高价 - max(收盘,开盘)) / (最高价 - 最低价)。
- 击败间距 = 关键 K 线与击败 K 线之间相隔的交易日数。

# 全项目去聚类复核清单（S1b）

> 生成: 2026-09-10 | 工具: `tools/year_robustness.py`（统一组件）+
> `tools/cluster_audit.py`（批量复核）
> 动机: 聚类假象已三例（15 篇 RPS 2015、23 篇 2018 失效、
> 28 篇 dd_250 2015），需制度化复核而非个案发现。

## 方法与判读

三项标准量（组件 `tools/year_robustness.py`，被
`holding_analysis`/`top_profile`/`exit_report`/`rps_check` 调用）：

| 量 | 定义 | 判读 |
|----|------|------|
| 分年效应表 | 每年 n / E / 中位 / 胜率 | 看年份分布与幅度 |
| **方向稳定性** | 效应符号一致年份占比 + 二项检验（H0: 方向随机） | **p<0.05 = 各年同向非随机**（✅） |
| **聚类贡献指数** | 1 − \|剔除最大样本年后的效应\| / \|全样本效应\| | **>0.5 = 聚类驱动**（效应主要由单一年份制造）；**负值 = 该年是反向拖累年**（剔除后效应更大） |

## 核心发现

1. **只有底背离（18 篇）方向稳定通过**（11/13 年同向，p=0.023）——
   与 24 篇"A3 是唯一分年稳的信号"独立互证。它是全项目**唯一**
   年度符号非随机的正期望信号。
2. **其余 8 条结论的年度符号稳定性均未通过**（p 0.09~1.00）:
   含义不是"结论假"，而是**年份间波动幅度大于效应与零线的距离**
   ——使用时必须按分年中位打折，不能把全样本 E 当无条件期望。
   例：腰斩 90 日全样本 19.93，剔除 2015 后 11.38，分年中位更低。
3. **聚类指数无一超过 0.5**（最高腰斩 0.429）——既有核心结论
   没有一条是"单一年份制造"的，28 篇 dd_250（0.404 全样本、
   拆年归零）属特征研究类，未入本表（其聚类性已在 28 篇标注）。
4. **负指数结论**（23 绝望承压 -0.630、19 杯柄 -0.348、16 双底
   -0.137）：最大样本年是**反向拖累年**——剔除后效应反而更大，
   说明这些结论在其聚集年份表现最差（如 2022 对绝望承压组）。

## 使用约定

- 任何新分组结论产出时，`tools/cluster_audit.py` 加入条目并跑；
- 方向稳定性未通过（⚠️）的结论，在文档表格附注"年度符号不稳定，
  按分年中位使用"；
- 聚类指数 >0.5 的结论，正文必须标注"聚类驱动"并给出剔除年后的
  效应值。

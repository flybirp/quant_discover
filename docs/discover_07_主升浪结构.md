# 发现：主升浪结构（回撤状态机 + 趋势线）

> 生成: 2026-08-31 | patterns: `main_dd50` / `main_trendline_zhixing_slow` / `main_trendline_ma60`
> 数据: 全市场 5062 只个股日线（2014-01 ~ 2026-08），前复权

> ⚠ 本篇为**事后归纳**型发现（波段从低点起算，收益不可实时交易），
> 价值在于选股画像与规律认知。

## 形态定义

- **回撤状态机（main_dd50）**：从绝对低点持续上涨，任意回撤 ≤50%，
  持续 ≥50 天且涨幅 ≥50%；
- **趋势线**：沿 MA60 / zhixing_slow 运行，无连续 2 日跌破，
  涨幅 >100%、持续 >200 天。

## 结论

1. **"安静的上涨"优于"刺激的上涨"**（原样复现）：回撤 <5% 的波段
   涨幅中位 389%、几乎必翻倍（95.6%）、1/3 涨 5 倍——但只占 3.6%，
   属于稀缺资源。
2. **回撤 45~50% 是噪音区**：占 2/3 的样本，涨幅中位 111%、胜率 56%，
   接近无信息。筛选主升浪时"容忍大回撤"等于放弃质量。
3. **超级大牛股双峰分布**：涨幅 >1000% 的 140 个波段中，回撤 <10%
   占 45%、>40% 占 28.6%，中间地带稀少——要么一路飙升，要么大起大落。
4. **长波段效率上台阶**：1500+ 天波段涨幅中位 190%（是 100 天波段的 1.9 倍），
   时间是主升浪的朋友。
5. 选股启示：优先关注**低波动、沿均线平稳上行**的个股（对应 zfzs 金叉
   后回踩不破的形态，见 `discover_01`），而非高波动"妖股"。

## 四、影响量级估算（以 06 腰斩 90 日为例，标注假设）

设：A 股 2014 年后退市约 200 家 / 全市场约 5,000 家 ≈ **4%**；
腰斩信号在退市股中的触发率高于均值，取 **4%~8%**；
该类样本的平均 90 日收益取 **-60%**（腰斩后退市整理期）。

```
真实 E ≈ (1-p) × 池内E + p × 退市样本E
p=4%:  0.96×19.93 + 0.04×(-60) = +16.7%（报告值高估 3.2pct，约 16%）
p=8%:  0.92×19.93 + 0.08×(-60) = +13.5%（报告值高估 6.4pct，约 32%）
```

**估算结论：正期望类结论的真实 E 比报告值低约 16%~32%**（假设
敏感，仅作量级参考）。方向（正期望）不变，但**任何仓位/资金
规划应以打折后的期望为准**。

## 五、使用约定

1. 一切"买入持有"类结论（E/胜率）视为**上界**，规划时打折；
2. 做空/负信号类结论（胜率下限）视为**下界**——方向不变；
3. 涉及尾部/退市的研究（28 篇等）正文必须标注本偏差；
4. 若将来获得含退市股的数据源，需重跑 24/27/28 三篇（高敏感）。

# 发现：微观 K 线组合补全（十字星 / 孕线 / 红三兵 / 黑三鸦）

> 生成: 2026-09-02 | patterns: `candle_doji`（n=110.5 万）/ `candle_inside_bar`
>（143.7 万）/ `candle_three_soldiers`（32.4 万）/ `candle_three_crows`（29.1 万）
> 口径：十字星 = 实体/振幅 ≤0.1；孕线 = 当日区间被昨日包含；
> 红三兵/黑三鸦 = 连续 3 根同向 K（实体各 ≥1%、收盘单调）。
> base = 组合最后一根 K 收盘。

黑三鸦是**做空方向形态的第四次证伪**（顶分型/吞没/M 头/黑三鸦），
且它是四个组合中唯一整体胜率 >50% 的——连跌三阴在 A 股是超跌信号
而非看跌信号。

## 背景支配：所有组合的收益由"前 20 天位置"决定

| 背景 | 十字星 | 孕线 | 红三兵 | 黑三鸦 |
|------|--------|------|--------|--------|

| 上涨中（0~10%） | +0.94% / 47.7% | +0.88% / 47.3% | +1.70% / 48.9% | +1.59% / 47.8% |
| 强势中（≥10%） | +0.90% / 46.0% | +0.97% / 46.0% | +0.03% / 43.1% | +1.48% / 46.7% |

两个关键观察：

1. **同背景下四种形态的收益差 <0.5pct**——K 线形状（十字/孕/兵/鸦）
   携带的信息量接近于零，"背景"列才是真正的信号源。
2. 唯一的亮点子集：**下跌中的红三兵**（+4.52%/58.2%）与
   **下跌中的黑三鸦**（+3.00%/52.7%）——恐慌末端的连续方向 K
   无论阴阳都是反弹前兆，与超跌体系（03/10/18 底背离）同构。

## 结论

1. **四种教科书 K 线组合全部无独立预测力**，其中两个方向与教科书
   相反（红三兵 <50%、黑三鸦 >52.5%）——微观形态证伪链就此闭环
   （12 分型 → 13 吞没 → 16 M 头 → 20 三兵三鸦）。
2. **"背景 > 形态"的最纯演示**：144 万孕线与 110 万十字星在同一
   背景分组下收益几乎相同，K 线形状本身不携带增量。
3. 可保留的唯一用法：**超跌背景下的连续阳线/阴线**作为超跌体系的
   辅助确认（红三兵×下跌 58.2%），但单独使用仍不如底背离（59.7%
   且净增量更大）。
4. 至此微观结构系列（12/13/14/20）结论完全收敛：**K 线微观形态在
   A 股只有两种价值——力度维度（分型深度）与背景载体，形状本身
   无信息**。

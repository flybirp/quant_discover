## 关于"再跌破率 72.9%"的口径警告

20 日内收盘再跌破支撑的比例高达 72.9%——但支撑就在 base 下方
1~2% 处，"再跌破"绝大多数是浅回踩而非形态失败（深 spring 组的
再破率反而最低 62.9%）。该指标对 spring 的失败判定过于敏感，
实战止损线应设在 spring 低点而非支撑位。

## 结论

1. **spring 是有效的中等强度买点**（净增量 +5pct，分年稳定），
  在超跌体系之外提供了"横盘语境"的买点补充。
2. **深 spring（≥5%）+ 隔日收回**是甜点组合（60.8%/+4.22%），
  样本 3,327 个（12 年全市场）不算稀缺。
3. 与 `discover_16` 的镜像关系正式闭环：**支撑二次测试的谱系**——
   base_break（深跌破不收回，78~81%）> spring（跌破后收回，54%）>
   双底（不跌破直接上攻，46.4%）。**出清越彻底，信号越强**；
   "假跌破后收回"介于两者之间，符合威科夫的原意（恐慌测试成功）。
4. "放量测试"维度无效——spring 的量能不携带增量信息。

# 发现：绝望期幸存者——周期级绝望的开始、结束与之后

> 生成: 2026-09-03 | 工具: `tools/despair_cycle.py`（主口径，可复现）、
> `tools/despair_check.py`（单日对照口径）
> 数据: 全市场 5,062 只日线（2014-2026）+ 中证1000
> 问题: "矮子里拔将军"——全市场绝望（约 4,000 支下跌、连跌数日、
> 周线级大跌）时，逆行者/抗跌者在**绝望结束后**表现如何？

## 口径定义

| 用词 | 精确定义 |
|------|---------|
| 绝望日 | 当日下跌家数占比 ≥ 80%（有效截面 ≥ 1,500 只） |
| **绝望期初期 T0** | 指数 20 日累计 ≤ -10% **且** 过去 20 日内绝望日 ≥ 2 个（周线级大跌 + 多日广度极端） |
| 低点 L | T0 起至企稳确认的指数最低收盘日 |
| **企稳 T1** | 自 L 反弹 ≥ 7% 且 L 后 ≥ 10 个交易日（排除单日反抽） |
| 主跌段 | 个股自 T0-20 交易日（下跌起点）至 L 的累计收益——**分组基准** |
| 逆行者 / 抗跌者 / 承压 / 大跌 | 主跌段 >0 / -5~0% / -15~-5% / ≤-15% |
| 收益 | 企稳日 T1 **收盘买入**，持有 20/60 日；ex = 相对中证1000 超额；MaxDD = 60 日内最低价/买入价 - 1 |

⚠ **两个关键口径决策**（缺一不可）：
1. **分组与买入分离**：分组看主跌段（下跌起点→低点），买入在企稳日——
   若分组区间含企稳反弹段，低点后暴力反弹的弹性股会冒充"逆行者/
   抗跌者"（污染检查：大跌组反弹段中位 +12.9%、75 分位 +22.1%）；
2. **主跌段起点回看 20 日**：T0 是"跌完 -10%"的确认日，下跌主体
   发生在 T0 之前，分组必须从下跌起点算，否则低点≈T0 的期会退化为
   全样本 seg=0。

三种企稳后类型：
- **V 型反转**（2015-08、2016-02、2016-05、2020-03、2022-04、2025-04）：
  大跌组碾压（73~95%）——修复期资金全面涌向超跌方向；
- **反弹夭折/二次探底**（2015-06、2015-07、2022-01）：全灭（6~33%），
  且跌得越深越惨——企稳确认是假信号；
- **结构分化**（2024-01 微盘危机）：逆行者 69% 最强、大跌组 37% 最弱
  ——市场分层时资金抱团强势股，超跌的微盘股被持续抛售。

## 结论

1. **周期级企稳后的将军是"适度出清"的中间层**：承压组（主跌段
   -15~-5%，n=14,975）胜率 56.4% 全场最高、MaxDD -12.14% 全场最浅
   ——跌出了修复空间，但没有跌穿基本面。与 `discover_04` base_break
   C 组甜点（跌破 10~15% + 非缩量最优）**同构：出清适中 = 甜点**，
   这次出现在市场宽度层面。
2. **逆行者（n=5,148）企稳后跑输**（超额 -0.09%，胜率 49.4% 全场
   最低）——整轮下跌（4~6 周）都在涨的强势股，在修复期补跌，与
   `discover_19` 杯柄（RPS≥80 最差）逻辑一致：修复期资金流向超跌
   方向，强势股被抽血。
3. **大跌组（n=36,085）是市场类型的杠杆**：E60 +7.00%、超额 +2.85%
   全场最高，但分期胜率从 95%（2015-08）到 10%（2022-01）——
   弹性不是质量，买大跌组等于押注"这次是 V 反转"。
4. **时间尺度语义链（本篇 + `discover_15` 合并）**：
   单日暴跌市红盘 = 假将军（承接疑似操纵，之后跑输）；
   120 日横盘高 RPS = 真将军（强势中继）；
   整轮下跌都在涨 = 企稳后补跌（均值回归）；
   **适度出清 = 修复期的真将军**。
5. 单日对照口径（`tools/despair_check.py`，episode 末日截面）结论
   保留：单日"抗跌者（-1~0%）"胜率 59.8% 最高、相对红盘组 12/12 年
   占优——单日抗跌=真实承接；与周期级结论不矛盾，是不同尺度。

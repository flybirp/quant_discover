# 发现文档（discovers）

本目录是项目量化发现的**唯一权威记录**。每篇文档对应一个或一组
pattern/analyzer/专题脚本，全部数字由统一架构产出、可一键复现，格式统一：
形态定义 → 样本概况 → 后续收益/分组洞察 → 结论 → 复现命令。

- 生成方式：`python3 run.py catch patterns/X.yaml` + `python3 run.py analyze analyzers/X.yaml`（专题见各篇）
- 数据基础：全市场 5062 只 A 股日线（2014-01 ~ 2026-08），前复权
- 统计口径：`analyze/stats.py`（n / E（期望） / 中位 / 胜率 / 盈亏结构），
  收益表统一为 **样本 / E（期望） / 中位 / 胜率** 四列；
  排序能力用 **RankIC**（信号列 × 前瞻收益的 Spearman 秩相关）度量，
  二元事件用胜率相对背景基准的增量；周 horizon 为真自然周

## 核心发现（按可操作性排序）

1. **腰斩买点**（06）：翻倍后单边腰斩 = 出清最彻底，90 日胜率 74%、
   中位 +15%。持有按季度设计。
2. **筑底深跌破甜点**（04）：跌破 10~15% + 量能不萎缩 = 恐慌释放，
   4 周 +13~16%；同深度缩量 = 无人接盘，坚决回避。
3. **安静上涨**（07/09）：主升浪回撤越小涨幅越大（<5% 回撤波段 95.6% 翻倍）；
   低回撤波段的回踩才值得买（创新高率 82%）。
4. **恐慌末端体系**（03/08/10）：加速下跌是最强前置过滤器——
   深跌+连跌+放量的底分型 84% 上涨率、深跌+缩量击败 76% 上涨率、
   超大波段 84% 跌幅集中在启动前 30 天。
5. **横盘的期权属性**（05/11）：横盘收益是右尾结构，正确用法是
   "横盘 + 突破触发 + 估值/量能过滤"——低估值买到下有底（PB<1
   向下仅 3.9%），缩量阴跌的横盘是危险品。
6. **金叉的用法**（01）：zhixing 金叉胜率仅 ~50%，但盈亏比稳定 1.6~1.8，
   只配做趋势跟踪体系的入场过滤器。
7. **微观形态的四条铁律**（12~14）：① 分型深度单调有效，浅分型无信息；
   ② K 线形态的"有效率"大部分是**背景基准**的功劳（涨多了基准本身
   就跌），形态自身增量通常只有个位数 pct——评估任何胜率必须先扣背景；
   ③ A 股做空方向信号的天花板（65%）远低于做多方向（84%），且"过度
   缩量"类反向风险信号（胜率 31%）比正向信号更可靠；④ 突破成败看
   **确认期回撤深度**而非仅看"是否跌破平台"：回撤 <3%（直接上）才
   是强势确认、≥8% 即隐性失败；等回踩会系统性只等到失败者。

## 规范

- 新增发现必须先有 pattern/analyzer/专题脚本输出，文档只记录可复现数字；
- 文档统一编号 `discover_NN_主题.md`，遵循统一模板；
- 结论必须注明样本量、分年度稳健性与口径警告（如前视偏差、去重口径）；
- **胜率/下跌率必须对照同背景随机基准**（基准数值见 `appendix.md`）——
  形态的"有效率"= 相对背景基准的增量，而非绝对数字；
- **所有用词的精确代码定义见 [appendix.md](appendix.md)**（复刻结论前必读，
  含量比两种口径、事件收盘价 vs maxup 最高价等易踩坑点）。
